# Smerk3rVisuals

Оригинальный клиентский visual-мод для Minecraft Java 1.21.11 на Fabric. Интерфейс выполнен в тёмном стиле с голубым акцентом и открывается клавишей **Right Shift**.

## Возможности первой версии
- GUI с категориями и переключателями модулей
- категории: HUD, Visuals, Interface
- переключение модулей прямо в меню
- неблокирующее игру меню
- автоматическая сборка через GitHub Actions

Это самостоятельная реализация с собственным кодом и оформлением, а не копия исходников или ресурсов FlyVisuals.

## Сборка
Нужны JDK 21 и Gradle 9.7.1. Из папки `Smerk3rVisuals` выполни:
```bash
gradle build
```
Готовый мод появится в `build/libs/`.

## Установка
1. Установи Fabric Loader для Minecraft 1.21.11.
2. Установи Fabric API 0.141.1+1.21.11.
3. Помести собранный `.jar` в папку `mods`.
4. Запусти игру и нажми **Right Shift**.

## Статус
Это первая версия GUI-клиента. Сейчас переключатели сохраняют состояние в текущем сеансе интерфейса; сами игровые HUD/visual-функции будут добавляться следующими обновлениями.
