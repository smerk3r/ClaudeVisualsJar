# ClaudeVisuals — Fabric 1.21.11

Создатели: **ClaudeCoder**, **ClaudeCode**, **smerk3r**

Клиентский мод: HUD-модули, визуалы, анимированный таб, красивое главное меню и меню функций.

## Как получить .jar

**Вариант 1 — на своём ПК** (нужен JDK 21 и Gradle 9.2+ или IntelliJ IDEA):
1. Распакуйте архив.
2. В папке проекта: `gradle wrapper --gradle-version 9.2.1`, затем `./gradlew build`
   (Windows: `gradlew.bat build`). Или просто откройте папку в IntelliJ IDEA и запустите задачу `build`.
3. Готовый мод: `build/libs/claudevisuals-1.0.0.jar` (файл без `-sources`).

**Вариант 2 — без установки ничего:** создайте репозиторий на GitHub, загрузите туда все файлы
проекта (вместе с папкой `.github`). Во вкладке Actions запустится сборка, и готовый .jar
появится в Artifacts (`ClaudeVisuals-jar`).

## Установка
Положите `claudevisuals-1.0.0.jar` и **Fabric API** в папку `mods` (Fabric Loader 0.18+, Minecraft 1.21.11).

## Свои клавиши (бинды)
У **каждой функции** есть свой бинд включения/выключения. Назначить его можно двумя способами:
1. В меню (Right Shift): вкладка **Клавиши** — нажмите кнопку справа от функции, затем нужную клавишу или кнопку мыши (Esc — убрать бинд). Там же «Сбросить все бинды». Бинд также есть в настройках каждой функции.
2. В ванильных настройках Управление → категория ClaudeVisuals.
Переменные клавиши: меню, зум (держать), скрыть HUD и все функции. Бинды сохраняются вместе с настройками игры. Модуль «Подсказки клавиш» показывает ваши текущие бинды.

## Клавиши по умолчанию
| Клавиша | Действие |
|---|---|
| Right Shift | Меню функций (поиск, категории, настройки) |
| Tab (держать) | Анимированный таб |
| C (держать) | Зум |
| N | Ночное зрение (вкл/выкл) |
| V | Авто-спринт (вкл/выкл) |
| H | Скрыть / показать HUD |

Настройки хранятся в `config/claudevisuals.json`.

## Функции
HUD: FPS, CPS, пинг, координаты+направление, скорость, биом, часы+дни мира, клавиши (WASD/пробел/мышь),
броня и предмет в руке, эффекты, **музыка (какой трек играет)**, подсказки клавиш, сервер, RAM, комбо,
счётчик предмета, статус.
Визуал: свой прицел (4 стиля), хитмаркер, виньетка, неоновая рамка, частицы экрана, ночное зрение,
зум, комфорт камеры. Движение: авто-спринт. Оптимизация: FPS-буст, лёгкий HUD.
Таб: анимированный (появление, волна строк, пинг-полоски, значок у вас).
Главное меню: свечение, частицы, анимированный логотип, кнопка ClaudeVisuals.

Ночное зрение работает только на клиенте. Некоторые серверы запрещают такие моды, смотрите правила сервера.
